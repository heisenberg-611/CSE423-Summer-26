# CSE423 - Computer Graphics Lab

This repository contains lab work and assignments for **CSE423: Computer Graphics** course (8th Semester at BRACU).

## 📁 Directory Structure

```
CSE423/
└── LAB/
    └── Lab1/
        ├── CSE423_OpenGL_Lab_Reference.ipynb    # Lab reference notebook with OpenGL concepts
        └── First Program/                        # Initial OpenGL programs
            ├── Hello_openGL.py                   # Basic OpenGL setup program
            ├── Lets_draw_sth.py                  # Drawing shapes with OpenGL
            └── OpenGL/                           # OpenGL Python bindings and libraries
```

## 🎯 Course Overview

This course focuses on **Computer Graphics** fundamentals using Python and OpenGL (Open Graphics Library). Students learn:
- OpenGL basics and graphics pipeline
- 3D coordinate systems and transformations
- Drawing primitive shapes
- Graphics rendering and visualization
- Python OpenGL bindings

## 🛠️ Getting Started

### Prerequisites
- Python 3.x
- OpenGL library support
- Required packages (typically PyOpenGL)

### Running the Programs

1. Navigate to the lab directory:
   ```bash
   cd LAB/Lab1/First\ Program/
   ```

2. Run a program:
   ```bash
   python Hello_openGL.py
   python Lets_draw_sth.py
   ```

## 📚 Resources

- **CSE423_OpenGL_Lab_Reference.ipynb** - Contains detailed reference materials, examples, and explanations for OpenGL concepts used in the lab
- **Hello_openGL.py** - Start here for basic OpenGL window setup
- **Lets_draw_sth.py** - Learn how to draw basic shapes and objects

## 📝 Notes
